# Toko Online

## Ringkasan
Aplikasi e-commerce untuk penjualan produk kerajinan. Backend memakai Laravel, frontend memakai Next.js, basis data PostgreSQL.

## Status
Fitur keranjang belanja dan katalog sudah selesai. Yang sedang dikerjakan adalah halaman pembayaran dan pelacakan pengiriman.
