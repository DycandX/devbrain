# Master Blueprint: Central AI Brain Hub (SSOT Multi-Agent & Multi-Device)

Dokumen ini merupakan rangkuman eksekutif dan arsitektur resmi yang menggabungkan seluruh hasil brainstorming (01 - 10) untuk membangun **Central Second Brain Hub** lintas perangkat dan lintas AI Agent dengan **Obsidian** sebagai antarmuka visual utama.

---

## 1. Visi & Tujuan Sistem

Membangun ekosistem memori terpusat (*Single Source of Truth*) di mana:
* Semua AI Agent (**Google Antigravity IDE, agy CLI, Claude Code, Hermes Agent, OpenCode, Codex**, dsb.) dapat saling berbagi konteks, memori jangka panjang, dan solusi teknis.
* Dapat diakses secara aman dari berbagai perangkat (**Laptop Pribadi, Laptop Kerja, Homeserver Jarvis, Mobile**).
* Pengguna manusia (*Human-in-the-Loop*) dapat memantau, mengedit, memvalidasi, dan menavigasi knowledge graph secara visual melalui **Obsidian**.

## 3. Matriks Komponen & Teknologi

| Layer / Komponen | Teknologi Terpilih | Peran & Alasan Pemilihan |
| :--- | :--- | :--- |
| **Networking** | **Tailscale** | Menghubungkan seluruh device dalam VPN privat terenkripsi tanpa port-forwarding. |
| **UI & Human SSOT** | **Obsidian** | Antarmuka Markdown, Canvas, Graph View, dan Dataview untuk monitoring manusia. |
| **Vault Sync** | **Syncthing** | Replikasi file `.md` real-time sub-detik antar laptop dan server secara P2P. |
| **Vector Database** | **Qdrant** | Ringan, cepat (Rust), mendukung hybrid vector + payload metadata filtering. |
| **Local Embedding** | **Ollama (`bge-m3` / `nomic-embed`)** | 100% lokal di Jarvis, hemat biaya API token, dan menjaga privasi kode. |
| **Agent Interface** | **FastMCP (Python / TypeScript)** | Protokol resmi standar industri (Model Context Protocol) untuk semua AI. |
| **Audit & Backup** | **Git Snapshot + Rclone** | Version control otomatis untuk mencegah kerusakan catatan akibat human/agent error. |


---

## 5. Alur Kerja Integrasi Multi-Agent

1. **Active Query (Read):** Saat Antigravity atau Claude Code memulai task, agent memanggil `search_brain("auth retry pattern")` melalui MCP Jarvis.
2. **Active Logging (Write):** Jika agent menghasilkan keputusan arsitektur penting, agent memanggil tool `record_adr(...)` atau `write_agent_log(...)`.
3. **Passive Harvesting (Background):** Daemon lokal di laptop memantau `~/.gemini/antigravity/brain/` dan `~/.claude/projects/`. Setiap sesi yang selesai otomatis diringkas dengan LLM lokal/Flash, disanitasi dari secrets/API keys, lalu disimpan ke folder `90_Agent_Inbox/`.
4. **Auto Vectorization:** Watcher di Jarvis mendeteksi file Markdown baru, memecah chunks, membuat embeddings via Ollama, dan mengindeksnya ke Qdrant secara instan.

## 6. Roadmap Rencana Implementasi Bertahap

```
[ Phase 1: Foundation (1-2 Hari) ]
├── Setup Tailscale di Jarvis Homeserver & Laptop
├── Setup Central Obsidian Vault & Pasang Syncthing
└── Buat struktur folder standar (00_System, 10_Projects, dsb.)

[ Phase 2: Server Memory Stack (2-3 Hari) ]
├── Deploy Docker Compose di Jarvis (Qdrant + Ollama bge-m3)
├── Buat FastMCP Server Gateway (Tools: search_brain, read_note, write_inbox)
└── Uji coba koneksi MCP via SSE dari laptop

[ Phase 3: Client Agent Connectivity (1-2 Hari) ]
├── Konfigurasi MCP di Antigravity IDE (~/.gemini/antigravity/mcp_config.json)
├── Konfigurasi MCP di Claude Code (~/.claude.json)
└── Buat custom prompt injector / context hook

[ Phase 4: Automated Ingestion & Distillation (2-3 Hari) ]
├── Pasang local harvester daemon (watchdog) di laptop
├── Implementasi Secret Sanitizer (Redactor API keys/tokens)
└── Implementasi LLM-based session summarizer ke Obsidian Inbox

[ Phase 5: Monitoring & UI Dashboard (1 Hari) ]
├── Setup Obsidian Dataview & Kanban boards
├── Visualisasi Graph View hubungan antar proyek dan knowledge
└── Setup automatic Git snapshot & backup rutin di server
```
