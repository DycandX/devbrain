# Master Blueprint: Central AI Brain Hub (SSOT Multi-Agent & Multi-Device)

Dokumen ini merupakan rangkuman eksekutif dan arsitektur resmi yang menggabungkan seluruh hasil brainstorming (01 - 10) untuk membangun **Central Second Brain Hub** lintas perangkat dan lintas AI Agent dengan **Obsidian** sebagai antarmuka visual utama.

---

## 1. Visi & Tujuan Sistem

Membangun ekosistem memori terpusat (*Single Source of Truth*) di mana:
* Semua AI Agent (**Google Antigravity IDE, agy CLI, Claude Code, Hermes Agent, OpenCode, Codex**, dsb.) dapat saling berbagi konteks, memori jangka panjang, dan solusi teknis.
* Dapat diakses secara aman dari berbagai perangkat (**Laptop Pribadi, Laptop Kerja, Homeserver Jarvis, Mobile**).
* Pengguna manusia (*Human-in-the-Loop*) dapat memantau, mengedit, memvalidasi, dan menavigasi knowledge graph secara visual melalui **Obsidian**.

## 3. Matriks Komponen, Embedding & Profil Deployment

| Layer / Komponen | Teknologi Pilihan | Peran & Alasan Pemilihan |
| :--- | :--- | :--- |
| **Networking** | **Tailscale** | Menghubungkan seluruh device dalam VPN privat terenkripsi tanpa port-forwarding. |
| **UI & Human SSOT** | **Obsidian** | Antarmuka Markdown, Canvas, Graph View, dan Dataview untuk monitoring manusia. |
| **Vault Sync** | **Syncthing** | Replikasi file `.md` real-time sub-detik antar laptop dan server secara P2P. |
| **Vector Engine** | **Qdrant (Server) / LanceDB (Local)** | Mendukung hybrid vector search, payload filtering, dan mode embedded lokal. |
| **Embedding Engine** | **Pluggable (FastEmbed CPU / Cloud API / Ollama)** | Sangat ringan (~150MB), bisa 100% offline tanpa GPU atau via API Key ($0 setup). |
| **Agent Interface** | **FastMCP (Python / TypeScript)** | Protokol standar resmi (Model Context Protocol) via Stdio (lokal) atau SSE (remote). |
| **Audit & Backup** | **Git Snapshot + Rclone** | Version control otomatis untuk riwayat commit dan pemulihan bencana. |

### 3 Profil Deployment Fleksibel:
1. **Profil 1: Standalone (1 Laptop Pribadi):** 1 perintah Python lokal, embedded LanceDB/FastEmbed, zero Docker, zero server.
2. **Profil 2: Multi-Laptop P2P:** Vault di-sync via Syncthing/Git antar laptop kerja & pribadi, masing-masing jalan lokal.
3. **Profil 3: Dedicated Homeserver (Jarvis SSOT):** Full Docker Compose di server rumah + FastMCP SSE over Tailscale.

## 5. Alur Kerja Integrasi Multi-Agent & Efisiensi Token

1. **Universal Skill Registry:** Folder `00_System/Agent_Skills/` disinkronkan ke client via Syncthing/Symlink (untuk Antigravity/AGY) atau diakses on-demand via FastMCP tool `load_skill()` (untuk Claude Code/Hermes).
2. **Efisiensi Token Maksimal (Hemat 60%-85%):** System prompt awal tetap ramping (~300-500 token). Konteks masa lalu dan file `SKILL.md` hanya ditarik secara *Just-In-Time* (JIT) ketika relevan, mencegah pemborosan context window.
3. **Active Query (Read):** Saat agent memulai task, agent memanggil `search_brain("auth retry pattern")` melalui MCP Jarvis.
4. **Active Logging (Write):** Jika agent menghasilkan keputusan arsitektur penting, agent memanggil tool `record_adr(...)` atau `write_agent_log(...)`.
5. **Passive Harvesting (Background):** Daemon lokal di laptop memantau `~/.gemini/antigravity/brain/` dan `~/.claude/projects/`. Setiap sesi yang selesai otomatis diringkas dengan LLM lokal/Flash, disanitasi dari secrets/API keys, lalu disimpan ke folder `90_Agent_Inbox/`.
6. **Auto Vectorization:** Watcher di Jarvis mendeteksi file Markdown baru, memecah chunks, membuat embeddings via Ollama lokal (0 biaya token), dan mengindeksnya ke Qdrant secara instan.

## 6. Roadmap Rencana Implementasi Bertahap

```
[ Phase 1: Foundation (1-2 Hari) ]
├── Setup Tailscale di Jarvis Homeserver & Laptop
├── Setup Central Obsidian Vault & Pasang Syncthing
└── Buat struktur folder standar (00_System/Agent_Skills, 10_Projects, dsb.)

[ Phase 2: Server Memory Stack (2-3 Hari) ]
├── Deploy Docker Compose di Jarvis (Qdrant + Ollama bge-m3)
├── Buat FastMCP Server Gateway (Tools: search_brain, read_note, write_inbox, load_skill)
└── Uji coba koneksi MCP via SSE dari laptop

[ Phase 3: Client Agent Connectivity (1-2 Hari) ]
├── Konfigurasi MCP di Antigravity IDE (~/.gemini/antigravity/mcp_config.json)
├── Setup Symlink folder Agent_Skills ke ~/.gemini/config/skills/
├── Konfigurasi MCP di Claude Code (~/.claude.json)
└── Buat custom prompt injector / context hook

[ Phase 4: Automated Ingestion & Distillation (2-3 Hari) ]
├── Pasang local harvester daemon (watchdog) di laptop
├── Implementasi Secret Sanitizer (Redactor API keys/tokens)
└── Implementasi LLM-based session summarizer ke Obsidian Inbox

[ Phase 5: Monitoring & UI Dashboard (1 Hari) ]
├── Setup Obsidian Dataview & Kanban boards
├── Visualisasi Graph View hubungan antar proyek dan knowledge
└── Setup automatic Git snapshot & backup rutin di server
```
