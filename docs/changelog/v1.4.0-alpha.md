## 🌟 Highlights & Key Features

### 1. Unified DWIM ("Do What I Mean") Ingestion CLI
* **Consolidated CLI Experience (`src/devbrain/cli/commands/ingest_cmd.py`):** Eliminated all argument friction by uniting all ingestion paths under `devbrain ingest [TARGET] [OPTIONS]`:
  * `devbrain ingest <repo_path>`: Ingests a single project or documentation repository.
  * `devbrain ingest --dir <path>` / `devbrain ingest --path <path>`: Tolerates alternative directory flags interchangeably without throwing `No such option` errors.
  * `devbrain ingest <container_workspace>`: Automatically discovers multi-project folders and batch-seeds sub-projects.
  * `devbrain ingest`: Automatically harvests AI sessions from Antigravity IDE and Claude Code.
  * `devbrain ingest all`: Performs full synchronous ingestion across projects, sessions, and the graph mesh.

### 2. Interactive IDE Deep Links & File Protocol Bridge
* **1-Click IDE Launch (`src/devbrain/harvester/project_harvester.py`):** Injects direct URI protocol links into every generated project card:
  ```markdown
  > 🔗 **Quick Actions:** [🚀 Open in IDE (VS Code / Antigravity)](vscode://file/E:/_PROJECT/my-app) | [📁 Open in File Explorer](file:///E:/_PROJECT/my-app)
  ```
* Seamlessly connects Obsidian knowledge cards directly to the developer's physical codebase editor.

### 3. Self-Ingestion Guard
* **Self-Check Mechanism (`src/devbrain/harvester/service.py`):** Prevents circular self-ingestion when scanning workspace directories where the active Obsidian vault resides.
