## [1.0.0-alpha] - 2026-08-29

### 🚀 Level 1 Milestone Complete: Standalone Local Zero-Friction Core

This release marks the full completion of **PRD Level 1 (Standalone Local Core)**. `devbrain` provides a single source of truth for multi-agent pair programming, enabling Google Antigravity IDE and Claude Code to read and write to an Obsidian Vault seamlessly with sub-20ms semantic search.

### 🌟 Key Highlights & Capabilities
1. **Core Scaffolder & Configuration (`src/devbrain/core/`):**
   * Pydantic schema validation for `.brainrc.json` with multi-tier path discovery (`find_config()`).
   * Non-destructive scaffolder generating the full 07 taxonomy (`00_System/`, `10_Projects/`, `20_Knowledge/`, `30_Decisions/`, `90_Agent_Inbox/`, `99_Daily/`, and `.brainignore`).
   * Clean separation of `.brain_data/` internal caches from user notes.
2. **Hybrid Search Engine (`src/devbrain/engine/`):**
   * **Dense Semantic Search:** FastEmbed CPU ONNX vectorizer using `BAAI/bge-small-en-v1.5` (384 dimensions, zero GPU required).
   * **Sparse Keyword Search:** Rank-BM25 with token normalization.
   * **Header-Aware Chunker:** Context-preserving section hierarchy with breadcrumb headers.
   * **Score Fusion:** Weighted combination ($0.6 \times \text{Dense} + 0.4 \times \text{BM25}$) with scope and tag filtering.
3. **Live Vault Watcher (`src/devbrain/watcher/`):**
   * Background file system listener (`watchdog`) with a 0.5s sliding-window `DebounceManager` for real-time incremental re-indexing during active typing.
4. **FastMCP Protocol Gateway (`src/devbrain/mcp_server/`):**
   * Built on official Python MCP 2.x SDK with Stdio transport.
   * 4 Core Memory Tools:
     - `search_brain`: Hybrid semantic search returning ranked Markdown results.
     - `get_project_context`: Direct retrieval of active project context notes from `10_Projects/`.
     - `write_agent_log`: Append-only session logs in `90_Agent_Inbox/` using immutable UUID partitioning (`{timestamp}_{device}_{uuid}.md`).
     - `load_skill`: Just-in-time loading of agent workflows from `00_System/Agent_Skills/`.
5. **AI Client Auto-Configurator (`src/devbrain/core/client_config.py`):**
   * Automatic zero-touch registration in **Google Antigravity IDE** (`~/.gemini/antigravity/mcp_config.json`, `~/.gemini/antigravity-ide/mcp_config.json`) and **Claude Code** (`~/.claude.json`).
6. **Unified Developer CLI (`devbrain`):**
   * `devbrain init`: Interactive onboarding wizard.
   * `devbrain status`: Vault health check and statistics table.
   * `devbrain index`: Manual full or incremental indexing.
   * `devbrain search`: Terminal hybrid search with colored match panels.
   * `devbrain serve`: MCP Stdio transport server.
   * `devbrain skill [list|add|symlink]`: Modular AI agent skill management.
   * `devbrain uninstall`: Safe IDE unregistration and clean cache teardown.
