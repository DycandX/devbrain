## [1.1.0-alpha] - 2026-08-29

### 🚀 Added
- **Multi-Agent Storage Discovery Engine (`src/devbrain/harvester/discovery.py`):**
  - Dynamic detection of active session stores for **Google Antigravity IDE** (`~/.gemini/antigravity-ide/brain/`), **Antigravity CLI** (`~/.gemini/antigravity-cli/`), **Claude Code** (`~/.claude/projects/`), **Cline/Roo Code** (`saoudrizwan.claude-dev/tasks/`), and **Aider**.
- **Secret Redaction Regex Sanitizer (`src/devbrain/harvester/sanitizer.py`):**
  - High-precision credential sanitizer automatically scrubbing OpenAI, Anthropic, Google AI Studio, and GitHub Personal Access Tokens, Bearer headers, and password assignments into safe `[REDACTED_SECRET]` placeholders.
- **Session Artifact Extractor & Obsidian Formatter (`src/devbrain/harvester/`):**
  - Extracts `walkthrough.md`, `implementation_plan.md`, and `transcript.jsonl` into clean, structured Markdown notes with standardized YAML frontmatter (`id`, `title`, `source`, `created`, `redactions_applied`, `tags`).
- **Unified Ingestion & Seeding CLI Commands (`src/devbrain/cli/commands/ingest_cmd.py`):**
  - `devbrain ingest [--from <agent>] [--dry-run] [--limit <n>] [--watch]`: One-click initial seeding and continuous session harvesting.
  - `devbrain pull`: Intuitive alias for `devbrain ingest`.
  - Built-in deduplication registry (`.brain_data/ingested_sessions.json`) preventing duplicate note creation on repeat runs.
  - Automatically triggers incremental vault indexing upon new file creation.
- **Automated Test Suite Expansion (`tests/test_ingestion.py`):**
  - Added 5 comprehensive unit and integration tests covering path discovery, regex sanitizer, XML/newline cleaning, deduplication, and CLI execution. Total 28 tests passing 100% in ~15s.

### 🐛 Fixed
- **Malformed YAML Frontmatter from Transcript Sessions (`src/devbrain/harvester/extractor.py` & `formatter.py`):**
  - Fixed issue where raw user prompts from `transcript.jsonl` containing multiline newlines (`\n`) and IDE XML tags (`<USER_REQUEST>`, `<ADDITIONAL_METADATA>`) caused YAML syntax errors in Obsidian Properties UI.
  - Implemented `clean_user_prompt()` to strip internal IDE XML tags and `sanitize_frontmatter_string()` to enforce safe, single-line sanitized titles and summaries.

### 🔄 Changed
- **Granular Storage Separation (`src/devbrain/harvester/discovery.py`):**
  - Separated monolithic `antigravity` source into `antigravity-ide` (`90_Agent_Inbox/antigravity-ide/`) and `antigravity-cli` (`90_Agent_Inbox/antigravity-cli/`) for clearer directory taxonomy in Obsidian.
- **Live Dataview Inbox Template (`src/devbrain/core/scaffolder.py`):**
  - Upgraded `_Inbox_Index.md` starter template to include an Obsidian Dataview query block that auto-refreshes live tables of recent sessions without requiring manual file edits.
