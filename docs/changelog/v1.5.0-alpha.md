## 🌟 Highlights & Key Features

### 1. Multi-Vault Federation Management (`src/devbrain/core/vault_federation.py`)
* **Cross-Vault Linking:** Connect any external Obsidian vault on the local disk into Central Brain memory without copying, moving, or duplicating files:
  * `devbrain vault link <path> [--alias <name>] [--mount]`
  * `devbrain vault unlink <alias>`
  * `devbrain vault list`
  * `devbrain vault sync`

### 2. Federated Hybrid Search Engine (`src/devbrain/engine/hybrid_search.py`)
* **Multi-Vault AI Memory:** Engine automatically discovers and indexes markdown files across the Central Vault and all linked external vaults.
* **Scope-Aware Querying:** Support for scoping queries to all vaults (`scope="all"`), local Central Vault only (`scope="central"`), or specific linked vaults (`scope="<alias>"`).
* **FastMCP Integration:** The `search_brain` tool in Antigravity IDE and Claude Code now automatically searches across all linked vaults.

### 3. Obsidian Sidebar Mounting (`--mount`)
* **Zero-Redundancy Directory Junctions:** Uses Windows Directory Junctions (`mklink /J`) and POSIX symlinks to mount linked vaults into `20_Knowledge/Linked_Vaults/<alias>/`, enabling immediate browsing, editing, and Graph View connectivity in Obsidian with **0 MB duplicate disk space**.
