# Changelog — Version 0.2.0-alpha

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0-alpha] - 2026-08-29

### 🚀 Added
- **Markdown & Frontmatter Parser (`src/devbrain/engine/parser.py`):**
  - Robust YAML frontmatter parser extracting metadata safely.
  - Tag extractor merging frontmatter tags and inline `#hashtags` (filtering out code blocks and markdown headings).
  - Wikilink extractor finding all `[[Wikilinks]]` references across vault notes.
  - Title extractor with frontmatter $\rightarrow$ `# Heading 1` $\rightarrow$ filename fallback logic.
- **Header-Aware Hierarchical Chunker (`src/devbrain/engine/chunker.py`):**
  - Section splitter preserving markdown heading stacks (`#`, `##`, `###`).
  - Breadcrumb hierarchy generator with deduplication (e.g. `[Architecture Overview] > Database Layer > Vector Search Engine`).
  - Paragraph-level sliding window sub-chunker for long texts exceeding token boundaries.
- **FastEmbed & Rank-BM25 Hybrid Search Engine (`src/devbrain/engine/`):**
  - FastEmbed CPU ONNX wrapper (`BAAI/bge-small-en-v1.5`) with lazy loading and single-thread CPU optimization for ultra-low RAM footprint.
  - Rank-BM25 tokenization and sparse keyword indexer.
  - Reciprocal Rank & Weighted Score Fusion:
    $$\text{Score} = 0.6 \times \text{DenseScore} + 0.4 \times \text{BM25Score}$$
  - Scope filtering by tag or folder path (`work`, `personal`, `all`).
- **Persistent Embedded Storage (`src/devbrain/engine/storage.py`):**
  - Local vector cache storing embeddings matrix (`vectors.npy`) and chunk metadata (`index_metadata.json`) in `.brain_data/`.
  - Modification timestamp tracker (`mtime`) enabling zero-redundancy incremental index updates.
- **Watchdog Live Vault Watcher (`src/devbrain/watcher/`):**
  - Debounce manager (`debounce.py`) preventing duplicate indexing during live typing in Obsidian.
  - Real-time file system listener auto-indexing created, modified, and deleted `.md` files in background.
- **CLI Commands (`src/devbrain/cli/commands/`):**
  - `devbrain index [--reindex] [--vault <path>]`: Manual indexing with progress bar and statistics table.
  - `devbrain search "<query>" [-n <limit>] [-m <mode>] [-s <scope>]`: Terminal search rendering ranked results in colored Rich panels.
- **Unit & Integration Test Suite (`tests/`):**
  - 10 new tests added covering parser, chunker, hybrid search, watcher, and CLI commands. Total 18 tests passing 100% in <6s.

### 🐛 Fixed
- Fixed UTF-8 charmap encoding error on Windows terminals for rich console emoji outputs.
- Fixed ONNX runtime BFC arena memory allocation during fast sequential embedding calls by tuning threads and batch size.
- Fixed breadcrumb title duplication when Markdown `# Heading 1` equals document title.
