## Ringkasan

Audit di [dokumen 48](../brainstorming/48-peran-llm-audit-vault-dan-arah-rag.md) menemukan cacat di hampir semua catatan vault utama. Rilis ini memperbaiki **penyebabnya** di kode pembuat catatan, dan menambahkan `devbrain lint` untuk memperbaiki **catatan lama** dengan aman. Vault utama sudah dimigrasi: 142 dari 143 catatan diperbaiki, dan lint kini tidak menemukan masalah.

Keputusan yang dipakai: **D14-1** kartu projek diberi `aliases` (nama berkas tetap `README.md`), **D14-2** tautan ke catatan harian yang tidak ada dihapus.

---

## 🚀 Ditambahkan

### `devbrain lint` (`maintenance/lint.py`, `core/schema.py`)
- Default hanya melapor. `--fix` memperbaiki yang aman diperbaiki.
- Frontmatter diubah per baris, bukan diserialisasi ulang, sehingga urutan kunci dan format baris lain tetap.
- Folder `00_System/Agent_Skills/` dikecualikan dari skema karena skill memakai format agentskills.io (`name`, `description`). Validitas YAML-nya tetap diperiksa.

| Aturan | Yang diperiksa | Perbaikan |
| :--- | :--- | :--- |
| `invalid-yaml` | Frontmatter yang tidak bisa dibaca YAML | Nilai yang gagal dibaca dikutip ulang sebagai JSON |
| `missing-frontmatter` | Catatan tanpa frontmatter | Ditambah `type`, `title`, `created`, `tags` |
| `missing-keys` | Kunci wajib `type`, `title`, `created`, `tags` | `created` dari `date` / `updated` / `last_scanned` / waktu berkas; `type` dari folder; `title` dari judul pertama |
| `project-aliases` | Kartu projek tanpa `aliases` | Ditambah nama projek dan nama folder |
| `broken-daily-link` | Tautan ke `99_Daily/<tanggal>` yang berkasnya tidak ada | Baris Timeline dihapus; tautan lain menjadi teks biasa |
| `noisy-title` | Judul atau isi sesi yang memuat teks harness | Teks dibuang; judul dibangun ulang dari tujuan sesi |
| `noisy-link-label` | Label tautan sesi di kartu projek yang menyalin judul kotor | Teks harness dibuang dari label |
| `legacy-suffix` | Teks ganda `(Live Dataview):` di riwayat sesi | Dibuang |

### `devbrain adr supersede <lama> <baru>`
- Status ADR lama menjadi `superseded` dengan `superseded_by`, dan ADR baru mendapat `supersedes`.
- Kedua catatan saling menaut di bawah judulnya. Isi ADR lama tetap utuh sebagai riwayat.
- Briefing dan `get_decisions` hanya menampilkan ADR berstatus `accepted`.

## 🐛 Diperbaiki (di sumbernya)

| Masalah | Penyebab | Perbaikan |
| :--- | :--- | :--- |
| Judul sesi Antigravity berisi `The user changed setting ...` | Hanya tag `<USER_SETTINGS_CHANGE>` yang dibuang, isinya tidak | Semua blok tag harness (huruf besar) dibuang beserta isinya |
| 30 tautan putus ke `99_Daily/` | Setiap catatan sesi menaut ke catatan harian yang tidak pernah dibuat | Tautan Timeline tidak lagi dibuat |
| 65 kartu projek tampil sebagai "README" di Obsidian | Semua kartu bernama `README.md` | Kartu baru punya `aliases`; kartu lama diperbaiki lint |
| Teks `(Live Dataview):` ganda | Tautan disisipkan di tengah baris judul bagian | Judul bagian tanpa akhiran; tautan disisipkan setelah baris judul |
| Frontmatter sesi rusak | Judul berisi garis miring terbalik (`E:\_PROJECT\...`) ditulis di dalam tanda kutip tanpa escape | Nilai frontmatter ditulis dengan `json.dumps` |
| Frontmatter skill rusak | Deskripsi berisi badge Markdown ditulis tanpa kutip | Deskripsi ditulis dengan `json.dumps` |
| Blok `dataview` ikut terindeks | Kode untuk plugin Obsidian dianggap isi catatan | Blok `dataview`, `dataviewjs`, `query`, `tasks`, `base` tidak diindeks |
| ADR-001 usang tetap disodorkan | Tidak ada cara menandai ADR yang digantikan | `adr supersede`; ADR-002 dibuat untuk model multibahasa |

Tambahan kecil:
- Kartu projek mencatat `created` dan mempertahankannya saat dipindai ulang.
- Catatan memori mendapat `title` dan `created`.
- Frontmatter di `User_Preferences.md` tidak ikut masuk briefing.

Sesudah migrasi:
- Tautan ke catatan harian yang tidak ada: 30 → 0.
- Catatan yang memuat teks harness: 34 → 0.
- Kartu projek dengan `aliases`: 0 → 66.
- `devbrain lint`: tidak ada masalah.
- ADR aktif: ADR-002. ADR-001 berstatus `superseded`.

Evaluasi retrieval tidak berubah (hit@1 hybrid 0,969, penolakan 6/6). Korpus evaluasi tidak memuat blok `dataview`, jadi dampak pembuangannya hanya terasa di vault nyata.

## ⚠️ Yang Perlu Dilakukan

- **Mulai ulang sesi agent** supaya server MCP memakai kode baru. Watcher server lama tetap mengindeks ulang catatan yang berubah, tetapi masih dengan aturan lama sampai dimulai ulang.
- Setelah dimulai ulang, `devbrain index` membangun ulang indeks sehingga blok `dataview` terbuang dari semua catatan.

---

## ⏭️ Keterbatasan

- `\_` di dalam tanda kutip ganda adalah escape YAML yang sah (berarti spasi tak terputus), jadi lint tidak bisa mendeteksinya. Catatan baru tidak lagi terkena karena nilai ditulis dengan `json.dumps`.
- Judul sesi lama yang terpotong karena panjang (bukan karena teks harness) dibiarkan.
- Dua skill yang sebenarnya projek (`temp-app`, `zulvikar-portofolio`) hanya diperbaiki frontmatter-nya; klasifikasinya belum.
