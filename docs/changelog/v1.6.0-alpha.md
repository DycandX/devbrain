## 🌟 Ringkasan Rilis

Rilis **v1.6.0-alpha** menandai lompatan besar DevBrain dari sekadar alat manajemen Obsidian menjadi **Universal Central AI Context & Memory Operating Hub (PAIOS Layer)**:
1. **🏛️ Architecture Decision Records (ADR Framework):**
   * Direktori khusus `30_Decisions/` di Vault untuk menyimpan keputusan arsitektural.
   * Perintah CLI `devbrain adr new "<title>" --project "<project>"` dan `devbrain adr list`.
   * Otomatisasi cross-linking catatan ADR ke kartu projek di `10_Projects/`.
2. **⚡ Context Assembly Engine (`context_build` & `devbrain context`):**
   * Merakit kartu briefing situasional instan (<0.2 detik) menggabungkan 5 tier konteks: Preferensi Pengguna, Status Projek, ADR Aktif, Cuplikan Knowledge Base Relevan, dan Riwayat Sesi Koding Terakhir.
   * Perintah CLI `devbrain context <project> [--task "<task>"]`.
3. **📜 Workspace Rules Generator (`devbrain rules init`):**
   * Auto-generator file aturan `AGENTS.md` dan `CLAUDE.md` terstandar dengan aturan *Hierarchy of Truth*.
4. **📦 SQLite Machine State & Relational Cache (`.brain_data/brain.db`):**
   * Embedded SQLite lokal untuk tracking memori, scope (`GLOBAL`, `PROJECT`, `TASK`, `SESSION`), skor confidence, status usang (*superseded conflicts*), dan cache hash file.
5. **🌐 Extended Skills Mesh (`devbrain skill link` & `devbrain skill attach`):**
   * Dukungan akses folder skill eksternal (misal `E:\_PROJECT\_agent-skill`) dan mounting langsung ke `.agents/skills/` pada projek koding spesifik.
6. **🔌 FastMCP Protocol Gateway Upgrade:**
   * Penambahan 4 tools baru: `build_task_context`, `get_user_context`, `get_decisions`, dan `record_decision`.
