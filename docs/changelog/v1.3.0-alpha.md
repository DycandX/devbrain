## 🌟 Highlights & Key Features

### 1. Smart Codebase Tree Analyzer & Entrypoint Detector
* **Tree Analyzer (`src/devbrain/harvester/tree_analyzer.py`):** Automatically traverses directories to generate clean ASCII file trees, intelligently ignoring `node_modules`, `.git`, `.venv`, `venv`, `target`, `dist`, and `build` folders.
* **Entrypoint & Infra Detector:** Recognizes key application entrypoints (`server.js`, `main.py`, `app.py`, `index.ts`, `main.go`, `src/main.rs`) and infrastructure specifications (`docker-compose.yml`, `Dockerfile`, `.env.example`).

### 2. Intelligent Project Card Synthesis for README-less Repositories
* **Architecture Synthesis (`src/devbrain/harvester/project_harvester.py`):** When a codebase lacks a `README.md` and manifest descriptions, `devbrain` synthesizes a comprehensive overview derived from languages, stack tags, entrypoints, and services.
* **Runnable Scripts Extractor:** Extracts runnable commands from `package.json` (e.g. `npm run dev` → `nodemon server.js`) and `pyproject.toml` into a dedicated `## ⚡ Runnable Scripts` markdown section.
* **Project Structure Section:** Automatically embeds a `## 🌳 Project Structure` ASCII block inside the project note.

### 3. Parent Workspace Container Auto-Delegation
* **Container Detection (`src/devbrain/harvester/inspector.py`):** When `devbrain ingest project <folder>` is executed on a container folder (like `_fxmedia`) that has no root manifests but contains multiple sub-projects, the system automatically detects `RepoType.CONTAINER`.
* **Seamless Batch Delegation:** Automatically scans and seeds all contained sub-projects into `10_Projects/` without creating empty or `UNKNOWN` root notes.
