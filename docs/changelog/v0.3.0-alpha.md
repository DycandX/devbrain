## [0.3.0-alpha] - 2026-08-29

### 🚀 Added
- **FastMCP Stdio Server (`src/devbrain/mcp_server/server.py`):**
  - Integrated Model Context Protocol (MCP 2.x SDK `MCPServer`) with stdio transport.
  - Attached background incremental indexing & live file watching.
  - Ensured all loggers write to `stderr` so stdio transport stream remains pure JSON-RPC.
- **4 Core AI Memory Tools:**
  1. `search_brain(query: str, limit: int = 5, mode: str = "hybrid", scope: str = "all")`: Runs FastEmbed + Rank-BM25 hybrid query and returns ranked Markdown matches with snippets and metadata.
  2. `get_project_context(project_name: str)`: Resolves project documentation, active roadmaps, and architecture guides from `10_Projects/`.
  3. `write_agent_log(summary: str, details: str, tags: list[str], author: str)`: Appends structured session notes to `90_Agent_Inbox/` using immutable UUID filenames (`{timestamp}_{device}_{uuid}.md`) and triggers live indexing.
  4. `load_skill(skill_name: str)`: Loads modular agent skill instructions from `00_System/Agent_Skills/{name}/SKILL.md` just-in-time.
- **AI Client Auto-Configurator (`src/devbrain/core/client_config.py`):**
  - Automatic zero-friction registration of `central-brain` server in **Antigravity IDE** (`~/.gemini/antigravity/mcp_config.json`, `~/.gemini/antigravity-ide/mcp_config.json`) and **Claude Code** (`~/.claude.json`).
  - Automatically invoked during `devbrain init`.
- **Agent Skill Management Commands (`src/devbrain/cli/commands/skill_cmd.py`):**
  - `devbrain skill list`: Renders a table of all active skills in `00_System/Agent_Skills/`.
  - `devbrain skill add <name>`: Generates a new skill template directory and `SKILL.md`.
  - `devbrain skill symlink`: Syncs vault skills to Antigravity global skills directory (`~/.gemini/config/skills/`).
- **Clean Uninstallation & Teardown (`src/devbrain/cli/commands/uninstall_cmd.py`):**
  - `devbrain uninstall [--purge]`: Safely unregisters MCP servers from IDEs, cleans symlinks, and optionally purges `.brain_data/` cache while strictly preserving all user Markdown notes.
- **CLI Subcommand Integrations (`src/devbrain/cli/main.py`):**
  - Registered `devbrain serve`, `devbrain skill`, and `devbrain uninstall`.
- **Unit & Integration Test Suite (`tests/`):**
  - Added 4 new test modules (`test_mcp_server.py`, `test_client_config.py`, `test_cli_sprint03.py`). Total 22 tests passing 100% in <10s.
