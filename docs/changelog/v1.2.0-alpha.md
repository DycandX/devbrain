## 🌟 Highlights & Key Features

### 1. Auto-Inspector & Multi-Language Manifest Parser
* **Auto-Inspector (`src/devbrain/harvester/inspector.py`):** Automatically classifies repositories into 4 distinct taxonomies:
  * **Active Project** (`10_Projects/`): When code manifests exist and Git commits belong to the developer (`role: "owner"`).
  * **Cloned Study Reference** (`20_Knowledge/External_Repos/`): When code manifests exist from third-party public repositories (`role: "study"`).
  * **Agent Skill Mesh** (`00_System/Agent_Skills/`): When repositories contain `SKILL.md` or a `skills/` directory.
  * **Knowledge / Markdown Docs** (`20_Knowledge/References/`): When repositories predominantly consist of Markdown documentation or awesome-lists.
* **Manifest Dependency Parser (`src/devbrain/harvester/manifest_parser.py`):** Reads dependencies, project descriptions, versions, and technology stacks from Python (`pyproject.toml`, `requirements.txt`), Node/TypeScript (`package.json`, `tsconfig.json`), Rust (`Cargo.toml`), Go (`go.mod`), and Docker (`Dockerfile`, `docker-compose.yml`).

### 2. Auto-Entity Linker Engine & Graph Density (Eliminasi Orphan Nodes)
* **Auto-Entity Linker (`src/devbrain/harvester/entity_linker.py`):** Automatically injects Obsidian `[[Wikilinks]]` into every ingested note:
  * Links AI session notes to their parent project hub: `- **Project Hub:** [[10_Projects/<Project>/README|<Project>]]`
  * Links notes chronologically: `- **Timeline:** [[99_Daily/YYYY-MM-DD|YYYY-MM-DD]]`
* **Zero-Click Project Auto-Provisioning:** If an AI session is ingested from a repository not yet registered in the vault, `devbrain` automatically discovers the repo and seeds its project card in `10_Projects/` seamlessly.
* **Bidirectional Backlink Injection:** Idempotently appends newly harvested sessions to the project README's `## 📜 Riwayat Sesi AI Terkini` section.

### 3. Targeted Single & Batch Ingestion CLI Commands
* **Targeted Single Ingest (`devbrain ingest project <path>`):** Ingests a specific directory or cloned repository instantly with optional manual type override (`--type auto | project | reference | skill | knowledge`).
* **Batch Workspace Scanner (`devbrain ingest projects [--dir <path>]`):** Automatically scans configured `workspace_roots` in `.brainrc.json` and bulk-seeds all codebase summaries into Obsidian.
* **Full Synchronous Ingestion (`devbrain ingest all`):** Executes repository scanning, AI session harvesting, and graph linking in a single consolidated command.
