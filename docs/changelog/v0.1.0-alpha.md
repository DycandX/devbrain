# Changelog — Version 0.1.0-alpha

All notable changes, new features, bug fixes, and architectural decisions for **`devbrain` v0.1.0-alpha** are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [0.1.0-alpha] - 2026-08-29

### 🚀 Added
- **Project Structure & Packaging:**
  - Configured `pyproject.toml` with `hatchling` build system, packaging metadata, and CLI entry point (`devbrain = devbrain.cli.main:app`).
  - Added full Python 3.10+ package structure under `src/devbrain/`.
  - Added `.gitignore` configured for Python virtualenvs, cache files, and `.brain_data/` local stores.
- **Core Configuration Manager (`src/devbrain/core/config.py`):**
  - Implemented `BrainConfig` Pydantic model for `.brainrc.json` with fields for `vault_path`, `device_name`, `embedding_provider`, `embedding_model`, `ignored_paths`, and `scope`.
  - Implemented automatic upward directory search for `.brainrc.json` via `find_config()`.
  - Implemented safe JSON serialization and deserialization via `save_config()` and `load_config()`.
- **Standard Vault Scaffolder (`src/devbrain/core/scaffolder.py`):**
  - Implemented non-destructive scaffolding algorithm for Obsidian Vaults.
  - Aligned 100% with the full taxonomy defined in `docs/brainstorming/07-taksonomi-vault-dan-standar-metadata.md`:
    - `00_System/` (`global_context.md`, `rules/general_rules.md`, `personas/backend_architect.md`, `Agent_Skills/example_skill/SKILL.md`)
    - `10_Projects/` (`_Project_Index.md`, `example_project/README.md`)
    - `20_Knowledge/` (`_Knowledge_Index.md`, `Architecture_Patterns/clean_architecture.md`, `Bug_Solutions/`, `Frameworks_Tools/`, `Security_Checklists/`)
    - `30_Decisions/` (`_Decisions_Index.md`, `ADR-001-use-fastmcp-and-fastembed.md`)
    - `90_Agent_Inbox/` (`_Inbox_Index.md`, `antigravity/`, `claude-code/`, `hermes/`, `manual_review/`)
    - `99_Daily/` (`_Daily_Index.md`)
    - `.brainignore`
- **CLI Framework & Interactive Commands (`src/devbrain/cli/`):**
  - Integrated `Typer` and `Rich` for modern colored terminal UI.
  - Added `devbrain init [path]` interactive wizard supporting local FastEmbed (CPU ONNX), Gemini API, and Ollama server selection.
  - Added `devbrain status [--vault <path>]` command rendering a detailed summary table of active parameters and note count breakdown.
- **English Localization:**
  - Localized all CLI help texts, prompts, error messages, and starter Markdown templates to professional English.
- **Automated Unit Testing (`tests/`):**
  - Added 8 unit tests in `test_config.py`, `test_scaffolder.py`, and `test_cli_sprint01.py` with 100% pass rate in <0.4s.

---

### 🔄 Changed
- Refactored `scaffolder.py` and `constants.py` directory definitions to include `30_Decisions/`, `99_Daily/`, `rules/`, and `personas/` subfolders.
- Updated `status_cmd.py` to count and report note statistics across all 7 taxonomy categories.

---

### 🛡️ Security & Integrity
- Ensured non-destructive operations during `devbrain init` to protect existing Markdown files from being overwritten.
- Added default exclusion rules for `.git`, `.obsidian`, `.stversions`, and `.brain_data`.
