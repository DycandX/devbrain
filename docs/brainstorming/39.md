bagaimana cara sync obsidain

Sinkronisasi Obsidian dapat dilakukan dengan beberapa metode tergantung kebutuhan, kenyamanan, dan kombinasi sistem operasi perangkat Anda.

---

**1. Obsidian Sync (Layanan Resmi)**
Metode paling stabil dan tanpa konfigurasi rumit, mendukung enkripsi *end-to-end* di semua platform (Windows, macOS, Linux, Android, iOS).

* Buka **Settings** → **Core plugins** → Aktifkan **Sync**.
* Masuk ke menu **Sync** di panel samping kiri, login dengan akun Obsidian berbayar Anda, lalu pilih **Create remote vault** atau hubungkan ke vault yang sudah ada.

**2. iCloud Drive (Khusus Ekosistem Apple)**
Pilihan gratis terbaik jika hanya menggunakan macOS dan iOS/iPadOS.

* Di iPhone/iPad, buat vault baru dan aktifkan toggle **Store in iCloud**.
* Di Mac, buka Obsidian dan pilih **Open folder as vault**, lalu arahkan ke direktori `iCloud Drive/Obsidian/[Nama Vault]`.
* *Tips:* Nonaktifkan opsi *Optimize Mac Storage* agar file markdown tidak berubah menjadi *placeholder* offline.

**3. Google Drive / OneDrive + FolderSync / Autosync (PC ke Android)**
Android membatasi akses langsung aplikasi ke penyimpanan *cloud*, sehingga dibutuhkan jembatan sinkronisasi dua arah (*two-way sync*).

* Simpan folder vault PC di dalam folder Google Drive for Desktop atau OneDrive.
* Di ponsel Android, instal aplikasi **FolderSync** atau **Autosync** dari Google Play Store.
* Buat *folder pair* dengan metode sinkronisasi **Two-way**: hubungkan folder *cloud* ke folder lokal penyimpanan internal ponsel (misal: `Documents/ObsidianVault`).
* Buka Obsidian Android, pilih **Open folder as vault**, lalu arahkan ke folder lokal tersebut.

**4. Obsidian Git Plugin (Gratis & Version-Controlled)**
Cocok jika terbiasa dengan Git dan ingin riwayat revisi penuh melalui repositori privat (GitHub/GitLab).

* Inisialisasi vault sebagai Git repository dan hubungkan ke *remote repository* privat.
* Di Obsidian Desktop, buka **Settings** → **Community plugins** → cari dan instal **Obsidian Git**.
* Konfigurasikan interval *auto-backup* (commit & push) dan *auto-pull* saat aplikasi dibuka.
* Di perangkat mobile, Anda dapat menggunakan aplikasi terminal/helper Git atau plugin pendukung untuk meng-clone repositori ke penyimpanan lokal.

**5. Syncthing (Sinkronisasi Peer-to-Peer)**
Metode *open-source* tanpa server pihak ketiga yang langsung menghubungkan perangkat lewat jaringan lokal atau internet.

* Pasang Syncthing di komputer dan Android.
* Tautkan kedua perangkat menggunakan Device ID.
* Buat *shared folder* dari vault komputer dan terima folder tersebut di penyimpanan lokal Android.
* Buka folder tersebut sebagai vault di aplikasi Obsidian Android.

Pilih salah satu metode termudah untuk menghubungkan Windows dan Android:

---

**Metode 1: Plugin "Remotely Save" (Paling Praktis & Gratis)**
Metode ini tidak memerlukan aplikasi tambahan di luar Obsidian. Sinkronisasi berjalan langsung di dalam aplikasi menggunakan akun Google Drive, OneDrive, atau Dropbox Anda.

1. **Di PC & Android:** Buka Obsidian → klik ikon **Settings** (roda gigi) → **Community plugins** → matikan *Restricted mode*.
2. Klik **Browse**, cari plugin **Remotely Save**, lalu klik **Install** dan **Enable**.
3. Buka pengaturan **Remotely Save** di kedua perangkat:
* Pilih penyedia cloud (misal: **OneDrive** atau **Google Drive**).
* Klik tombol otorisasi/login ke akun Anda.
* Aktifkan opsi **Auto Run** (misal tiap 5–10 menit atau saat aplikasi dibuka).


4. Klik ikon panah melingkar (sync) di menu bilah samping kiri untuk mulai sinkronisasi.

---

**Metode 2: Syncthing (Paling Cepat & Real-Time, Gratis)**
Metode ini menyinkronkan file langsung antar-perangkat secara lokal tanpa mengunggah database catatan ke server cloud.

1. Pasang **Syncthing** di Windows dan aplikasi **Syncthing-Fork** di Android.
2. Buka Syncthing di kedua perangkat, lalu tautkan dengan scan QR Code perangkat.
3. Di PC, tambahkan folder vault Obsidian Anda sebagai *Shared Folder* dan bagikan ke perangkat Android.
4. Di Android, terima folder tersebut dan arahkan ke lokasi folder vault yang tadi Anda buat.

---

Jika ingin yang 100% instan tanpa konfigurasi teknis sama sekali, opsi berbayar resmi adalah **Obsidian Sync** (cukup login akun di menu *Settings* → *Sync*). Namun, untuk jalur gratis, **Remotely Save** dengan OneDrive/Google Drive adalah pilihan paling simpel.
